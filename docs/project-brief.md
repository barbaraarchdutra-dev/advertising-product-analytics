# Advertising Product Analytics

## Objetivo

Analisar dados de produtos publicitários para identificar padrões
de performance, eficiência e oportunidades de negócio.

## Pergunta de negócio

Como os dados de campanhas, anunciantes e inventário publicitário
podem apoiar decisões sobre performance e eficiência dos produtos?

## Tecnologias

- SQL
- SQLite
- Python
- Pandas
- Data Visualization
- Dashboard
- Data Storytelling
